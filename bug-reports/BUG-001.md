# BUG-001 — Samsung Galaxy S7 muestra imagen incorrecta

## Información

- **Módulo:** Catálogo de productos
- **Severidad:** Medium
- **Prioridad:** Medium
- **Estado:** Open

## Precondiciones

La aplicación web se encuentra disponible y se puede acceder al catálogo de productos.

## Pasos para reproducir

1. Ingresar a la aplicación.
2. Acceder a la categoría **Phones**.
3. Localizar el producto **Samsung galaxy s6**.
4. Observar su imagen.
5. Localizar el producto **Samsung galaxy s7**.
6. Observar su imagen.
7. Comparar las imágenes de ambos productos.

## Resultado esperado

Cada producto debe mostrar una imagen correspondiente al modelo seleccionado.

## Resultado actual

El producto **Samsung galaxy s7** muestra la misma imagen que **Samsung galaxy s6**.
