# Test Plan — QA Web Testing

## 1. Objetivo

Validar las funcionalidades principales de la aplicación web Product Store mediante pruebas funcionales, identificando errores que puedan afectar la experiencia del usuario.

## 2. Alcance

Las pruebas se enfocan en las siguientes funcionalidades:

- Registro de usuarios
- Inicio de sesión
- Catálogo de productos
- Categorías
- Detalle de productos
- Carrito de compras
- Eliminación de productos del carrito
- Proceso de compra

## 3. Tipos de pruebas

- Pruebas funcionales
- Pruebas positivas
- Pruebas negativas
- Pruebas exploratorias
- Pruebas de regresión
- Pruebas Smoke

## 4. Ambiente de pruebas

**Aplicación:** Product Store  
**URL:** https://www.demoblaze.com/  
**Navegador:** Google Chrome  
**Fecha de ejecución:** Agosto 2026

## 5. Criterios de prueba

Las funcionalidades se consideran correctas cuando cumplen el comportamiento esperado definido para cada caso de prueba.

Los defectos encontrados serán documentados en la carpeta `bug-reports` junto con sus respectivas evidencias.

## 6. Evidencias

Las capturas de pantalla relacionadas con los defectos y resultados relevantes se almacenarán en la carpeta `test-evidence`.

## 7. Resultados

Los resultados de las pruebas ejecutadas serán consolidados en el archivo:

`test-results/test-results.md`
