# QA Web Testing

## 📌 Descripción

Proyecto personal de QA enfocado en el diseño, ejecución y documentación de pruebas funcionales sobre la aplicación web Product Store (Demoblaze).

El proyecto simula un proceso de pruebas manuales, desde la definición del alcance y diseño de casos de prueba hasta la ejecución, documentación de evidencias y reporte de defectos.

## 🎯 Objetivo

Validar las principales funcionalidades de la aplicación e identificar comportamientos que puedan afectar la experiencia del usuario.

## 🔍 Funcionalidades evaluadas

- Registro de usuarios (Sign Up)
- Inicio de sesión (Login)
- Catálogo de productos
- Carrito de compras
- Cálculo y actualización del total
- Proceso de compra

## 🧪 Tipos de pruebas realizadas

- Pruebas funcionales
- Pruebas positivas
- Pruebas negativas
- Pruebas exploratorias

## 📊 Resultados

| Métrica | Resultado |
|---|---:|
| Casos de prueba ejecutados | 15 |
| Casos PASS | 15 |
| Casos FAIL | 0 |
| Defectos reportados | 1 |

Durante las pruebas exploratorias se identificó un defecto visual en el catálogo: el producto Samsung Galaxy S7 muestra la misma imagen utilizada para Samsung Galaxy S6.

## 🐞 Defecto identificado

**BUG-001 — Samsung Galaxy S7 muestra imagen incorrecta**

- Módulo: Catálogo de productos
- Severidad: Medium
- Prioridad: Medium
- Estado: Open

El reporte incluye precondiciones, pasos para reproducir, resultado esperado, resultado actual y evidencia visual.

## 🛠️ Herramientas utilizadas

- GitHub — documentación y control de versiones
- Google Chrome — ejecución de pruebas
- Markdown — documentación de casos de prueba y defectos

## 📂 Estructura del proyecto

- `test-plan/` — Plan de pruebas
- `test-cases/` — Casos de prueba ejecutados
- `bug-reports/` — Defectos encontrados
- `test-evidence/` — Evidencias de ejecución
- `test-results/` — Resumen de resultados
