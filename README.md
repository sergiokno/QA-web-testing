# QA Web Testing

## 📌 Descripción

Proyecto personal enfocado en la práctica de pruebas de software sobre una aplicación web.

El objetivo es aplicar un proceso básico de QA, desde el análisis de las funcionalidades hasta la ejecución y documentación de las pruebas.

## 🎯 Objetivos

- Analizar las funcionalidades de la aplicación.
- Identificar escenarios de prueba.
- Diseñar y ejecutar casos de prueba.
- Registrar y documentar defectos encontrados.
- Realizar pruebas de regresión.
- Documentar los resultados de las pruebas.

## 🧪 Tipos de pruebas

- Pruebas funcionales
- Pruebas Smoke
- Pruebas de regresión
- Pruebas exploratorias
- Pruebas positivas y negativas

## 🛠️ Herramientas

- GitHub
- Navegador web
- Excel / Google Sheets

## 📂 Contenido del proyecto

- Plan de pruebas
- Casos de prueba
- Reportes de defectos
- Evidencias de ejecución
- Resumen de resultados
